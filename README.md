# 3D Helicopter Simulator (TypeScript + Three.js)

Vite + TypeScript + Three.js で作られた、本格的な物理演算を搭載したヘリコプターシミュレーターです。
<img width="1912" height="1032" alt="スクリーンショット 2026-06-02 082647" src="https://github.com/user-attachments/assets/e9c9b8e1-ddd5-4a06-8a6f-e7007eaa06f7" />

## 特徴
- **クォータニオン物理演算:** ジンバルロックのない滑らかな3軸回転
- **反トルク効果:** メインローターの回転に伴うリアルな機体の旋回挙動
- **地面効果 (Ground Effect):** 地面付近での揚力ボーナス
- **スプリング追従カメラ:** 画面酔いを防ぐドラマチックなカメラワーク

## 操作方法
- **W / S**: コレクティブ（ローター出力の昇降）
- **A / D**: ヨー（テイルローターによる左右旋回）
- **矢印キー (↑/↓/←/→)**: サイクリック（ピッチ・ロールによる機体の傾き）
